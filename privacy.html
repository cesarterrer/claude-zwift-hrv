Privacy Policy

Claude-Zwift HRV · last updated 3 September 2026

Claude-Zwift HRV is a personal, single-user application. It is used by its developer on their own Google account and their own health data. It has no other users.

What data is accessed

With the account holder's explicit consent, the application reads the following from the Google Health API:

  • Daily heart-rate variability
  • Daily resting heart rate
  • Sleep duration

It requests read-only scopes. It does not write to, modify or delete any Google Health data.

How the data is used

These values are transferred to the account holder's own private intervals.icu training log, so recovery metrics can be viewed alongside cycling and strength training data. That is the application's only purpose.

Storage and retention

An OAuth refresh token is stored locally on the account holder's own computer, in a permission-restricted file. Health values are stored in the account holder's own intervals.icu account. No data is stored on any server operated by this application, because no such server exists.

Sharing

No data is sold, shared, transferred or disclosed to any third party. The only destination is the account holder's own intervals.icu account, at their direction.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is not used for advertising, is not sold, and is not used to train any model.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also ends all access.
