# Claude-Zwift HRV

Consent-screen pages for a personal, single-user Google Cloud OAuth app.

The app reads its owner's own heart-rate variability, resting heart rate and sleep duration from
the Google Health API (read-only scopes) and writes them into the owner's own
[intervals.icu](https://intervals.icu) training log.

These pages exist because Google requires a home page, privacy policy and terms-of-service URL on
a verified domain before an OAuth consent screen can be published.
